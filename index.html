ABOUT CASEFILE

A changed basis.
An explained request for review.

Press Next to follow the fictional case. The engine panel initially shows recorded output produced by the preserved Python engine. Press Run actual tool to execute those same Python files in this browser.

The source-link discovery and identification assessment are human-supplied case inputs. When a person corrects a separate identification-assessment record, the engine follows the declared relationship to the earlier decision and requests reassessment. The original witness report remains unchanged.

Every person, place, report, and outcome in the case is fictional. The browser worker computes review requests; it does not find the child, rank leads, discover shared origins, or make investigative decisions.

The note-only and missing-link controls are alternate experiments. They do not change the fixed story. Source links alone establish neither truth nor independence. The story JSON-LD and the actual Python ledger export are separately labeled.

This is a new demonstration of the later standalone ledger. It does not reproduce the paper’s earlier evaluation, validate CASE/UCO conformance, or establish a tamper-proof history. The copied engine retains its licenses and CaseLinker attribution.
